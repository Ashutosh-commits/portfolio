View project ›
  • Shipped a QR-first cafe ordering and operations system on React 19, TypeScript, Tailwind CSS 4 and Supabase: menu browsing, table sessions, live orders and admin workflows across 6,500+ lines of typed code.

BroKar

  • Built and deployed a full-stack Indian real-estate platform with React 18, TypeScript, Express, Prisma and PostgreSQL: 2,000+ listings from scraped data behind 6 REST route modules.
  • Engineered a two-stage ML pricing pipeline in Python FastAPI using XGBoost (600 estimators) + LSTM (24-step lookback), serving 1–10 year forecasts trained on 8,000 rows, 15 cities and 14 features.

  • Optimised delivery with gzip and caching; the project documentation records an estimated ~70% bundle reduction.

Kiku

View project ›
  • Built Kiku as a mood-aware food discovery platform on React 18, Node/Express 5 and MongoDB, covering recommendations, restaurant discovery, saved items, recipes and a food assistant.
  • Integrated a live Swiggy/Zomato price-comparison scraper as a separate service: same-restaurant + same-dish matching on menu-level prices, with 24-hour caching, a 7-day stale fallback, request deduplication and circuit breakers.

About Me

Freelance developer, UI designer and unapologetic fish nerd. I build software that survives real shops, real clients — and looks good doing it.

Hi, I'm Ashutosh — a freelance web developer (MERN stack) and UI/UX designer who graduated with a BCA from Galgotias University in 2026. I build web apps end to end: React and TypeScript up front, Node and Python behind them, and a dash of machine learning when the problem actually asks for it.

My design instincts didn't come from a design school — they came from fish tanks. I keep four aquariums and love aquascaping, and arranging rock, wood and plants into a scape taught me about focal points, depth and negative space long before I wrote a line of CSS. Add a sketchbook, some paint, and you get someone who can't stop fiddling with the details.

Lately that means real work for real people: I sold my Food Mahal OMS project to a local restaurant, built a custom offline QR scanner for a small snack shop, and I'm now taking FrameVault to a client as a complete product. Between deadlines I'm scraping, scaping and learning something random.

How I build

I don't type every line by hand. I use agentic AI such as Claude Code and Antigravity to write the code, then I review it, fix the errors and bugs it leaves behind, and own the result. Most of my time goes into system design: shaping the UI, the architecture and the data flow up front, so the product feels smooth, works the way it was designed and ships early without cutting quality.
