ReactNode.jsFastAPIML

BroKar

View project ›
  • Built and deployed a full-stack Indian real-estate platform with React 18, TypeScript, Express and PostgreSQL, supporting 2,000+ listings and scraped property data.
  • Engineered a two-stage ML pricing pipeline in Python FastAPI using XGBoost + LSTM, exposing REST predictions for 1–10 year property forecasts.

  • Deployed the stack across Vercel + Railway + Neon + Upstash, with Redis caching, nginx gzip and a 3-job GitHub Actions CI/CD pipeline with Playwright E2E coverage.
  • Optimised the delivery bundle with gzip compression and caching; the project documentation records an estimated ~70% bundle reduction from gzip.

ReactNode.jsMongoDBAI
View project ›

Kiku

View project ›
  • Built Kiku as a food discovery and personalisation platform combining mood/craving input, recommendations, restaurant discovery, saved items, recipes and price comparison.
  • Implemented same-restaurant + same-dish comparison across supported providers; comparison results are normalised to menu-level price data rather than delivery fees, ETAs or checkout totals.
  • Added 24-hour comparison caching, a 7-day stale fallback, in-flight request deduplication, rate limits and circuit-breaker handling for unreliable upstream providers.
  • Designed PIN input as a 6-digit discovery hint rather than an exact delivery address, avoiding fabricated delivery availability, ETA or fee claims.
  • Implemented an on-device mood scan using browser-side MediaPipe; the camera starts only after explicit user action, stops after the scan and raw frames are not uploaded.
  • Built deterministic recommendation/recipe/comparison fallbacks so core food discovery continues even when optional Cloudflare Workers AI is unavailable or rate-limited.
  • Hardened the Node/Express API with Helmet, request IDs, Zod validation, HttpOnly/SameSite cookies, scrypt password hashing, endpoint-specific rate limits and provider URL allowlisting.

About Me

Freelance developer, UI designer and unapologetic fish nerd. I build software that survives real shops, real clients — and looks good doing it.

Hi, I'm Ashutosh — a freelance full-stack developer and UI designer who graduated with a BCA from Galgotias University in 2026. I build web apps end to end: React and TypeScript up front, Node and Python behind them, and a dash of machine learning when the problem actually asks for it.

My design instincts didn't come from a design school — they came from fish tanks. I keep four aquariums and love aquascaping, and arranging rock, wood and plants into a scape taught me about focal points, depth and negative space long before I wrote a line of CSS. Add a sketchbook, some paint, and you get someone who can't stop fiddling with the details.

Lately that means real work for real people: I sold my Food Mahal OMS project to a local restaurant, built a custom offline QR scanner for a small snack shop, and I'm now taking FrameVault to a client as a complete product. Between deadlines I'm scraping, scaping and learning something random.
